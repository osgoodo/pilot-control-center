# Pilot Control Center

Lightweight tool for a supervised, on-site biometric collection pilot (250 validated Contributions in 6 weeks, Atlanta, GA).

**Live page:** open `index.html` (GitHub Pages serves it at the repository's Pages URL).

## What's inside
- **Schedule & cost engine** – pre-production calculator. Inputs default to the delivery plan; the day-by-day schedule, capacity fit, staffing hours, cost, price and invoices recalculate instantly. Scenario buttons cover higher makeups, 3 required sessions, losing a station and more.
- **Command center** – daily ops dashboard as of W5 Monday 08:00, built on 8 days of simulated collection data: KPIs, rule-based alerts with owners, plan vs actual sessions, quality by supervisor, quota fill and today's summary.

## Data
`Pilot_Collection_Data.xlsx` is the sample dataset (tabs: Participants, Sessions, Plan, Devices, Quotas, Settings). Import it into Google Sheets to run the project day to day, then download as .xlsx and use **Load data** on the Command center tab to refresh the dashboard. Data stays in the browser; nothing is uploaded.

All names and IDs are fictional.
